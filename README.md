# チェキ練習機

チェキ（instax）のファインダーと実際の写りのズレ（パララックス）を体験して練習する Web アプリ。

- 対応機種：mini 12 / mini 41 / mini 99 / SQUARE SQ40 / WIDE 400
- モード：出題（採点あり）・フリー・写真（撮った写真を覗く）・ライブ（スマホのカメラ映像）
- シャッター後、現像されたプリントに「ファインダーで見えていた範囲」を重ねて答え合わせ
- 採点は写り方（顔アップ〜全身）に応じた頭上の余白・横位置・ピント・明るさで評価

## 使い方

GitHub Pages で `index.html` を公開し、スマホのブラウザで開く。
ライブモードは HTTPS 上でカメラの使用を許可すると動作する。

## 注意

焦点距離・フィルムサイズ・クローズアップ時の視差補正の有無はメーカー公表情報をもとにしている。
ファインダー位置・視野率・フラッシュの効き方は推定値（アプリ内「機種データを調整」で実機に合わせられる）。
